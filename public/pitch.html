Dataset, demonstration and sources +

This page uses the published GSE270392 soybean-root dataset: 7,496 nuclei and the original authors’ UMAP coordinates. The interactive map displays those coordinates, not a spatial layout. The highlighted group contains 388 nuclei.

The annotation and decision-recall captures come from one recorded Celloras experiment. Its marker reference is associated with the same study, so this demonstrates the workflow rather than independent annotation accuracy. A match does not establish publication readiness, and an unresolved group is not proof of novelty.

Current reference comparison uses marker evidence. Direct comparison of expression patterns between studies is future work. Nightshift investigation is implemented but disabled pending model connection and a successful live workflow.
