# Celloras pitch deck

[PowerPoint — editable](Celloras-Pitch-Deck.pptx) · [PDF — ready to present](Celloras-Pitch-Deck.pdf) · [Speaker notes and sources](speaker-notes.md)

Ten slides for the GenAI hackathon, prepared on 25 October 2026. Present slides 1–9; keep slide 10 as the source appendix. The deck follows one question: **What are these cells, what supports that interpretation, and what did we decide?**

## Story

1. Celloras: investigate plant cell identity, starting with soybean.
2. The work behind a label: compare genes, check references, retain reasoning.
3. Ask → inspect → review → return in one conversation.
4. The real soybean-root dataset: 7,496 nuclei across 12 groups.
5. Root hair evidence and Zetaris's versioned marker reference.
6. Meterless H-MEM recalls a researcher's corrected decision with its source.
7. Application, agent, scientific tools, reference adapter and memory architecture.
8. Observed annotation outcomes and numerical/workflow checks.
9. Independent validation, own datasets and additional plants as next steps.
10. Scientific sources, implementation links and original pitch-deck references.

## References and assets

The structure draws on the **original Airbnb deck**, as reproduced in [this annotated comparison](https://www.startups.com/articles/airbnb-pitch-deck-teardown-and-redesign), and the **original Buffer 2011 deck**, embedded in [the founder's account](https://buffer.com/resources/from-0-to-1000000-users-the-journey-and-statistics-of-buffer/). Airbnb informed the simple problem–solution progression; Buffer informed the focus on concrete proof. Their assets and business metrics are not reused.

The Celloras logo is the supplied brand artwork. All product screenshots and scientific figures come from actual Celloras runs captured on 25 October 2026. The map is the application's full annotation export; the dot plot contains measured expression. The H-MEM screenshot shows the latest illustrative review for group 6: unresolved pending independent evidence, while its calculated Root hair candidate remains unchanged.

The PowerPoint contains editable text, architecture shapes, speaker notes, source links and a native chart with its embedded 7/1/4 data snapshot. Product screenshots and the exported scientific plots remain images. Detailed scientific scope is in [annotation methods](../annotation-method.md); sponsor implementation and test pointers are in [the sponsor explanation](../sponsor-explanation.md).
