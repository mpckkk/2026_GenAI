# Celloras hackathon pitch

[PowerPoint](Celloras-Pitch-Deck.pptx) · [PDF](Celloras-Pitch-Deck.pdf)

**Four slides, roughly two minutes.** No separate cover or appendix.

1. **The agent:** the approved opening with the actual soybean cell map, unchanged.
2. **The research task:** identify the cell groups in a soybean root. A clear without/with comparison starts with uploading H5AD.
3. **The working result:** the actual card returned for uploaded data, Zetaris reference retrieval, measured gene activity and the provisional Root hair suggestion.
4. **The next question:** H-MEM recalls the saved provisional review. Links open the recall and the activity dashboard for that same experiment.
